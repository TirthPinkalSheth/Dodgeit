# DodgeIt

A small Unity game built as part of early game dev practice. Built for Android (APK included in the repo).

## Stack

- Unity
- ShaderLab / HLSL (custom shaders)
- C#

## Play it

Download DodgeIt.apk from this repo and install it on an Android device, or open the project in Unity to run it in the editor.
